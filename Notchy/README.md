# Notchy Website

صفحات عربية ثابتة لتطبيق Notchy، جاهزة للنشر على GitHub Pages.

## الصفحات

- `index.html` — الصفحة الرئيسية
- `about.html` — عن التطبيق
- `privacy.html` — سياسة الخصوصية
- `terms.html` — شروط الاستخدام
- `contact.html` — التواصل والدعم
- `feedback.html` — الشكاوى والمقترحات
- `arabic.html` — الواجهة العربية
- `404.html` — صفحة غير موجودة

## النشر

ارفع محتويات هذا المجلد إلى جذر مستودع GitHub مستقل، ثم فعّل GitHub Pages للنشر من الفرع الرئيسي ومجلد الجذر. لا يحتاج الموقع إلى خادم أو خطوة بناء.

## ملاحظة الخصوصية

تصف سياسة الخصوصية سلوك نسخة Notchy الحالية. حدّثها إذا أضيفت لاحقًا تحليلات أو حسابات أو مزامنة سحابية أو أي اتصال شبكي.
